# 013 — CLI (argparse, language detection flow, info subcommand)

## Parent

`docs/glossate-prd.md`

## What to build

Complete `cli.py` — the full argparse entry point for GLOSSATE, integrating the language detection flow, progress display, and all CLI flags.

**Language detection flow** (when `--source` is not given):
1. Sample three 10-second clips at 20%, 50%, and 80% of the audio duration.
2. Run `transcriber.detect_language()` on each clip.
3. Majority-vote the results; show detected languages + confidence to the user.
4. Prompt: "Detected language: Arabic (ar). Proceed? [Y/n]" with a 5-second auto-proceed timeout.
5. `--source` bypasses this entirely — no sampling, no prompt.

**Flags**:
- `--source LANG` — explicit source language
- `--target LANG` — target translation language (omit for transcription-only)
- `--format [srt|vtt|json]` — default: srt
- `--asr-model [tiny|base|small|medium|large]` — default: large
- `-o, --output PATH` — explicit output path
- `--device [auto|mps|cuda|cpu]` — default: auto
- `--verbose` — activates `logging` output (sets `logging.basicConfig(level=DEBUG)`)

**`glossate info` subcommand**:
- Clears the console, prints header panel, then System + Models panels (implemented in scaffold issue 001 — wire it up to the full CLI here)

**Progress integration**:
- `GlossateProgress` shown during all runs
- Extract stage skipped (marked complete) when input is already audio
- Translate stage skipped when no `--target` given

Include integration tests in `tests/test_cli.py` with mocked API calls.

## Acceptance criteria

- [ ] `glossate audio.wav` transcribes and writes `audio.srt` to the default output path
- [ ] `glossate audio.wav --target tr` transcribes + translates to Turkish
- [ ] `glossate audio.wav --source ar` bypasses language detection sampling
- [ ] Language detection samples at 20/50/80% of audio duration
- [ ] Majority vote correctly selects the most common detected language
- [ ] Auto-proceed fires after 5 seconds with no user input
- [ ] `--verbose` activates logging output
- [ ] `glossate info` prints header + System + Models panels and exits 0
- [ ] `glossate video.mp4` extracts audio before transcribing (Extract stage active)
- [ ] Extract stage is skipped when input is `.wav`/`.mp3`/`.m4a`/`.flac`
- [ ] Translate stage is skipped when `--target` is not given
- [ ] `GlossateProgress` is visible during the run
- [ ] All cases covered by tests with mocked API; `pytest tests/test_cli.py` passes
- [ ] `mypy` clean on `cli.py`
